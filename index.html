Ek awaaz sirf tumhare liye 🎙️

Baby, meri awaaz mein bhi ek chhota sa surprise hai. 💗

Apna voice note add karne ka tareeka:
  1. Phone ka Voice Recorder app kholo.
  2. Apni natural voice mein kuch pyaari baatein record karo.
  3. Recording ko voice-note.mp3 naam se save karo. Agar recorder M4A file banata hai, toh uska asli naam note kar lo.
  4. GitHub repository mein audio file upload karo, bilkul usi folder mein jahan index.html hai.
  5. Neeche audio player mein voice-note.mp3 ko apni file ke exact naam se match karo.

Voice note ke liye ek idea:
“Hi Mera Baby… bas tumhe yaad dilana tha ki tum mere liye kitni special ho. Yeh chhota sa surprise tumhari smile ke liye hai. I hope tumhe pasand aaye. Love you, meri pyaari si jaan. 💗”

Agar audio abhi upload nahi kiya, toh player nahi chalega. File upload karne ke baad page dobara kholo. Voice note ko public repository mein rakhne se koi bhi link wala insaan use sun sakta hai.
